# OPS DECK Update 0008

Овој update додава:

- **Финансии**
  - P&L табела по месец
  - рачно внесување приходи и трошоци
  - месечни приходи по извор и бренд
  - капитал по сметка/валута
  - претплати што автоматски создаваат месечни трошоци
- **Линкови до готова работа**
  - во Лендинг студио и Креативно студио секој task има поле за линк
  - по зачувување, линкот станува копче **Отвори** директно во редот
- **Брендови**
  - Drive изглед поделен по бренд
  - папки: Истражувања, Мокапи, Креативи, Документи и Друго
  - upload, отворање и бришење документи
  - фајловите се чуваат во приватен Supabase Storage bucket

## Инсталација

### 1. GitHub

Отпакувај го update ZIP-от и прикачи ги сите фајлови од `ops-deck` папката во постојниот GitHub repository.

Кликни **Commit changes**.

### 2. Supabase

Отвори:

**SQL Editor → New query**

Копирај ја целата содржина од:

`supabase/migrations/0008_finance_brand_drive_and_delivery_links.sql`

Залепи ја и кликни **Run**.

Очекуван резултат:

`Success. No rows returned`

Миграцијата автоматски создава:

- Finance табели
- Brand Drive табела
- приватен Storage bucket `brand-drive`
- RLS policies
- Finance и Brands permissions
- автоматска функција за претплати

### 3. Netlify

Не треба нов environment variable. Update-от го користи постоечкиот:

`SUPABASE_SERVICE_ROLE_KEY`

По GitHub commit, Netlify треба автоматски да deploy-ира.

Ако не започне:

**Netlify → Deploys → Trigger deploy → Deploy site**

### 4. Пристап за тимот

Во **Тим → Измени акаунт** ќе се појават новите страници:

- Финансии
- Брендови

Финансии е скриена по default за обични членови. Сопственикот може да им даде пристап.

Брендови е достапна како работна Drive страна. Корисник може да ги брише своите фајлови; owner/admin/manager може да управува со сите.

## Како работат претплатите

Netlify ја повикува функцијата `generate-subscriptions` секој ден. Кога ќе дојде денот за наплата, активната претплата автоматски создава P&L expense трансакција.

Функцијата е idempotent: повторно повикување нема да создаде дупликат за истиот месец.
