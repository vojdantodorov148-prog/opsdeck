# OPS DECK update 0006

Овој update додава:

- нов, поширок и помодерен gamified campus на Home;
- delete опција за производи во листата и на product detail;
- избор на повеќе пазари во една Quick Action;
- комбинирање на повеќе типови испораки, пример `2 × Адверторијал`, `3 × Статичен оглас`, `2 × Видео оглас`;
- автоматско делење на мешаната задача по пазар и фабрика, без двојно внесување;
- „Мој ден“ е строго приватен за најавениот корисник;
- текстовите изменети со моливчето се синхронизираат realtime кај сите најавени корисници.

## Инсталација

1. Замени ги фајловите во истиот GitHub repository со фајловите од овој пакет.
2. Во Supabase отвори **SQL Editor → New query**.
3. Копирај ја целата содржина од:
   `supabase/migrations/0006_multi_market_realtime_and_my_day_privacy.sql`
4. Кликни **Run** и провери да пишува `Success`.
5. Netlify автоматски треба да започне deploy. Ако не започне, отвори **Deploys → Trigger deploy**.
6. По `Published`, освежи ја апликацијата со `Cmd + Shift + R`.

## Како работат задачите со повеќе пазари

Една Quick Action може да има:

- повеќе пазари;
- повеќе лендинг испораки;
- повеќе креативни испораки.

OPS DECK автоматски креира посебна задача за секој избран пазар и за секоја потребна фабрика. Така лендинг работата оди во Landing Factory, а креативната работа во Creative Factory.
