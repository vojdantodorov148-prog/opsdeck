# OPS DECK Update 0012

## Што е сменето

### 1. Пазарот / државата е секогаш посебно поле кај задачите
- Новите автоматски task titles повеќе не го лепат пазарот на крај од името на производот.
- Во Tasks и во Landing/Creative Factory секоја задача има посебна, видлива ознака `Пазар: CODE · Име`.
- Во Task Detail има големо посебно поле `Пазар / држава`.
- Во My Day се прикажува посебен market badge.
- На Home preview се прикажува market code.
- Известувањето за нова задача го содржи пазарот одделно од насловот.
- Постоечките Quick Action задачи со производ автоматски се нормализираат за државата да не остане скриена во долг task title.

### 2. Финансии е направена од нула и има само 2 сегменти

#### Капитал
- Активни сметки: Кеш, ProCredit, Mercury + можност за додавање други.
- Секоја сметка има моментално салдо и валута.
- Салдото можеш рачно да го смениш кога сакаш.
- Секоја рачна промена се запишува во `Историја` со старо салдо, ново салдо, датум/час и кој ја направил промената.
- Можеш да тргнеш сметка кога салдото е 0; ако има историја, се архивира наместо да се уништи историјата.

#### Трансакции
- Приход / Трошок.
- Датум, опис, износ и сметка.
- При додавање приход, парите автоматски се додаваат на избраната сметка.
- При додавање трошок, парите автоматски се одземаат од избраната сметка.
- Ако избришеш трансакција, салдото автоматски се враќа.
- Опционално повторување: неделно, месечно или годишно.
- Повторливите трансакции се генерираат автоматски преку Netlify scheduled function.
- Повторувањето може да се стопира директно од редот на трансакцијата.

Старите P&L / Месечни приходи / Претплати табови повеќе не се прикажуваат.

## Инсталација

1. Отпакувај `ops-deck-update-0012.zip`.
2. Во истиот GitHub repository направи Upload/Replace на сите фајлови од пакетот.
3. Commit message: `OPS DECK Update 0012`.
4. Supabase → SQL Editor → New query.
5. Пушти ја **само** миграцијата `0012_market_field_and_simple_finance.sql`.
6. Очекувано: `Success. No rows returned`.
7. Почекај Netlify автоматски да направи deploy. Ако не, Deploys → Trigger deploy.
8. Не се потребни нови environment variables. Постоечкиот `SUPABASE_SERVICE_ROLE_KEY` се користи за автоматските recurring трансакции.

## Брз тест

### Пазар
1. Додели задача на производ со многу долго име и избери Хрватска.
2. Во Tasks/Factory провери дека името може да се скрати, но `Пазар: HR · Хрватска` е посебно и целосно видливо.
3. Отвори ја задачата и провери го посебното поле `Пазар / држава`.

### Финансии
1. Финансии → Капитал → отвори ProCredit → смени салдо → Зачувај.
2. Отвори `Историја` и провери дека промената е запишана.
3. Додај приход 1,000 EUR на ProCredit → ProCredit треба автоматски да се зголеми за 1,000.
4. Додај трошок 100 EUR на ProCredit → автоматски да се намали за 100.
5. Избриши ја таа трансакција → 100 EUR автоматски да се врати.
6. Додај повторлив трошок и избери `Секој месец`; на трансакцијата треба да има badge `Месечно`.
