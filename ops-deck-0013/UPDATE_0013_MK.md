# OPS DECK Update 0013 — Product Library Upgrade

## Што е сменето

### Производи
- Производите се редат **најновите најгоре**.
- Додаден е **search bar** по име, SKU или бренд.
- Додаден е брз **преглед/филтер по бренд**. Alpine, Origon и Ветерче се прикажуваат со кратките имиња, а ако има и друг бренд ќе се појави автоматски.
- Лево од името на производот има **thumbnail** од првата продукт слика.

### Секој производ
- **Бриф** е задолжителен за нов производ и при измена.
- **Најмалку една продукт слика** е задолжителна. Може да се додадат повеќе.
- Првата слика е главна/thumbnail во листата Производи.
- **Агли** се опционални и може да има неограничено повеќе. Секој агол има име + опис.
- Product Detail → Преглед сега покажува галерија, бриф и сите агли.
- Кај постоечки производи без слика, при следното менување ќе треба да се додаде слика.
- Ако постоечки производ имал стар текст во „Преглед/notes“, миграцијата го копира како почетен бриф за да не се изгуби.

## Инсталација
1. Отпакувај го `ops-deck-update-0013.zip`.
2. Во истиот GitHub repository → **Add file → Upload files** и замени ги фајловите.
3. Commit message: `OPS DECK Update 0013 - Product Library`.
4. Во Supabase → SQL Editor → New query пушти ја **само** `0013_product_library_upgrade.sql`.
5. Очекуван резултат: `Success. No rows returned`.
6. Почекај Netlify да направи automatic deploy. Ако не почне: Deploys → Trigger deploy.
7. Не се потребни нови environment variables.

## Брз тест
- Отвори Производи: провери brand filters + search.
- Додај нов производ: без бриф или без слика копчето за зачувување не треба да биде активно.
- Додај 2-3 слики и 2 агли.
- По зачувување, првата слика треба да се гледа како мала слика лево од името.
- Отвори го производот и провери галерија + Бриф + Агли.
