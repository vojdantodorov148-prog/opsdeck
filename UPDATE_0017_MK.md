# OPS DECK Update 0017 — Veterche prices

Овој update е само code change. НЕ треба Supabase SQL migration.

## Што менува

- За сите Ветерче производи цените во UI се прикажуваат со суфикс `ден.`.
- При додавање/уредување Ветерче производ, валутата автоматски се третира како MKD.
- REST API при креирање Ветерче производ автоматски користи MKD.
- Не се прави конверзија на бројките.

## Инсталација

1. Отпакувај го ZIP-от.
2. Upload/replace ги фајловите ВНАТРЕ од папката директно во root на истиот GitHub repo.
3. Не upload-ирај ја wrapper папката како под-папка.
4. Почекај Netlify deploy да стане Published.

Нема SQL чекор за овој update.
