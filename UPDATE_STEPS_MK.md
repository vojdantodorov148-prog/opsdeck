# Како да го пуштиш овој update без Terminal

Овој пакет е update за веќе поставениот OPS DECK.

## 1. Ажурирај ги фајловите на GitHub

1. Отвори го ZIP пакетот.
2. Во твојот GitHub repository отвори **Add file → Upload files**.
3. Прикачи ги сите фајлови и папки од пакетот, со истата структура.
4. Избери **Commit changes**.

Netlify автоматски ќе почне нов deployment.

## 2. Пушти ја новата Supabase миграција

Во Supabase отвори **SQL Editor → New query**.

Отвори го фајлот:

`supabase/migrations/0005_macedonian_team_access_and_editable_text.sql`

Копирај ја целата содржина, залепи ја во SQL Editor и кликни **Run**.

Ова додава:

- пристап до страници по корисник;
- текстови што се менуваат преку малото моливче;
- македонски системски известувања;
- линк за Маркетинг Интелигенција;
- поставка за лого;
- е-пошта во профилите.

## 3. Додај ја серверската Supabase тајна во Netlify

Ова е потребно само за креирање и бришење тимски акаунти од апликацијата.

Во Supabase копирај го **Secret key / service_role key**.

Во Netlify, во Environment variables, додај:

- Key: `SUPABASE_SERVICE_ROLE_KEY`
- Value: твојот Supabase secret/service-role key

Овој клуч никогаш не смее да почнува со `VITE_` и не смее да биде ставен во GitHub.

Потоа направи **Redeploy** ако Netlify веќе завршил со deployment-от.

## 4. Постави го логото

Во апликацијата отвори:

**Поставки → URL на логото**

Внеси директен URL до PNG или SVG фајлот и зачувај.

## 5. Провери

По deployment-от провери:

- страниците се на македонски;
- Vision Center го нема;
- во Тим можеш да додадеш, уредиш и избришеш акаунт;
- во Тим можеш да избереш пристап до страници;
- во Алатки можеш да избришеш апликација;
- во Тестирање можеш да ги измениш двата надворешни линка;
- картичката Маркетинг Интелигенција го отвора `https://marketron-mi.pages.dev/#operator`;
- малото моливче е долу десно;
- Поставки дозволува промена на име, позиција, профилна слика и лозинка;
- кампусот на Почетна е поширок и понизок.
