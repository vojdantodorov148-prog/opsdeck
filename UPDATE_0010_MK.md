2. Commit message: `OPS DECK Update 0010`.
3. Во Supabase → SQL Editor → New query пушти ја само миграцијата:
   `0010_due_time_sku_product_link_and_direct_completion.sql`
4. Очекуван резултат: `Success. No rows returned`.
5. Почекај Netlify да направи автоматски deploy. Ако не започне, Deploys → Trigger deploy.
6. Не се потребни нови environment variables.
